
# FitnessGPT AI

An AI-powered Fitness and Diet Assistant.

## About the Project

FitnessGPT AI is a web application that helps users with fitness guidance, healthy diet suggestions, and workout recommendations using Artificial Intelligence.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Groq AI
- Firebase

## Features

- AI Fitness Chatbot
- Healthy Diet Suggestions
- Workout Recommendations
- Voice Assistant
- User Profile
